🔌 Интеграционный модуль 1С:Фреш ↔ ASP.NET Core 

&#x20;

Готовый шаблон для быстрого подключения внешних систем к \*\*1С:Фреш\*\* через REST API (OData).   

Использует \*\*ASP.NET Core 9\*\*, \*\*PostgreSQL\*\*, \*\*Docker Compose\*\*. 

&#x20;

\## ✅ Возможности 

&#x20;

\-	CRUD‑запросы к справочникам и документам облачной 1С:Фреш 

\-	Логирование всех обращений в PostgreSQL 

\-	Готовые примеры работы с контрагентами и номенклатурой 

\-	Swagger для ручного тестирования 

\-	Полная изоляция в контейнерах 

&#x20;

\## 🚀 Быстрый старт 

&#x20;

1\. \*\*Получите доступ к демо‑версии 1С:Фреш\*\* 

\-	Зарегистрируйтесь на \[1cfresh.com](https://1cfresh.com) (бесплатный тестовый период 30 дней) 

\-	Создайте любую конфигурацию, например «Управление небольшой фирмой» 

\-	После входа в приложение нажмите \*\*«Синхронизация и интеграции» → 

«Настройки HTTP-сервисов»\*\* 

\-	Включите OData‑интерфейс и скопируйте: 

\-	URL вашего приложения (например `https://my.1cfresh.com/...`) 

\-	Логин и пароль от информационной базы (не от личного кабинета 1С:Фреш!) 

&#x20;

2\.	\*\*Настройте подключение\*\*   

&#x20;  Отредактируйте `src/OneSIntegration.Api/appsettings.Development.json`: 

&#x20;  ```json 

&#x20;  "OneS": { 

&#x20;    "BaseUrl": "https://my.1cfresh.com/DemoUNF", 

&#x20;    "UserName": "odata\_user", 

&#x20;    "Password": "your\_password" 

&#x20;  } 

``` 

&#x20;

3\.	Запустите проект    ```bash    docker-compose up --build 

&#x20;  ``` 

4\.	Откройте Swagger 

&#x20;  Перейдите на http://localhost:5000/swagger и протестируйте эндпоинты. 

&#x20;

📚 Структура базы данных 

&#x20;

Таблица IntegrationLogs (автоматически создаётся через EF Core миграции): 

&#x20;

· Id (Guid) 

· Endpoint (string) – какой метод 1С вызывался 

· Request (jsonb) – тело запроса 

· Response (jsonb) – ответ 

· StatusCode (int) 

· CreatedAt (timestamp)
